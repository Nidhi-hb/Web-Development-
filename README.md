# 1) chess.html
# ♟️ Chess Board Using HTML & CSS

A simple **8×8 chessboard layout** created using **HTML and CSS**. This project demonstrates how HTML tables and CSS selectors can be used to create a visually structured chessboard.

## 📌 Project Overview

This project creates a chessboard using an HTML `<table>` with **8 rows and 8 columns**. CSS is used to create the alternating black-and-white pattern of the chessboard.

The board structure is built using table rows and cells, while CSS selectors automatically apply the black background to alternating cells.

## ✨ Features

- 8 × 8 chessboard layout
- Alternating black and white squares
- Built completely with HTML and CSS
- Simple and beginner-friendly implementation
- No JavaScript or external libraries required

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**

## 📂 Project Structure

```text
Chess/
│
├── chess.html
└── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `chess.html` in any web browser.
4. The chessboard will be displayed.

## 🧠 Concepts Learned

- HTML tables
- Table rows and cells
- CSS selectors
- `nth-child()` selector
- CSS borders
- CSS background colors
- Basic webpage structure

## 📸 Project

# 2) form.html(mockexam)

A beginner-friendly **Student Registration Form** created using **HTML5**. The project demonstrates how different HTML form elements can be combined to collect student information.

The form includes fields such as first name, last name, date of birth, email, mobile number, gender, address, city, pincode, state, and country.

- Last Name field
- Date of Birth field
- Email field
- Mobile Number field
- Gender selection
- Address field
- City field
- Pincode field
- State field
- Country field
- Hobbies selection
- Educational qualification table
- Submit button
- Reset button
- Basic HTML form validation attributes

## 🎓 Qualification Section

# 3) lrapido.html
# 🛵 Rapido-Inspired Ride-Hailing Website

A responsive **Rapido-inspired ride-hailing website** created using **HTML and CSS**. The project focuses on recreating the visual structure of a modern transportation service landing page.

## 📌 Project Overview

This project is a frontend practice project inspired by the design and layout of a ride-hailing platform.

The website contains a navigation bar, hero section, ride booking interface, services section, earning section, app download section, and footer.

## ✨ Features

- Responsive navigation bar
- Ride-hailing themed hero section
- Pickup and drop location fields
- Book Ride button
- Services section
- Quick Pickup feature
- Best Fares feature
- Ride availability section
- "Earn with Rapido" section
- App download section
- Customer and Captain app sections
- Footer with navigation and social media information
- Responsive layouts for desktop, tablet, and mobile devices

The navigation includes Home, About Us, Safety, Careers, Blog, Press, and Contact Us sections.

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- CSS Flexbox
- CSS Media Queries
- Responsive Web Design

## 🎨 Design

The website uses a yellow, black, white, and light-gray visual style inspired by the Rapido brand.

The hero section contains the heading **"India's #1 Ride-Hailing App"**, pickup/drop inputs, and a booking button.

## 📱 Responsive Design

CSS media queries have been included for different screen sizes:

- Desktop
- Tablet
- Mobile
- Small mobile screens

The layout changes from a horizontal structure to a vertical structure on smaller screens.

1. Open the project in **Visual Studio Code**.
2. Install the **Live Server** extension.
